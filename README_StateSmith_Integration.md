# StateSmith + Blockly Tool Integration

This directory contains the Blockly Tool as a submodule, demonstrating the integration between StateSmith's Liquid template output and Adafruit IO Blockly Actions.

## Overview

StateSmith can now generate Liquid templates that are compatible with the Blockly Tool and Adafruit IO Actions. This enables state machine logic to be used within IoT workflows.

## Example Files

### `test_sunset_countdown.liquid`
A test template demonstrating advanced Liquid syntax for calculating time differences, including:
- Date manipulation and timestamp conversion
- Mathematical operations (division, modulo)
- Conditional logic and nested if statements
- Variable assignments and calculations

### `statemachine_example.liquid`
An example generated by StateSmith's Liquid transpiler, showing:
- State machine structure output
- Event handling patterns
- State transition loops
- Adafruit IO feed integration with `feeds['feed-key']` syntax
- Smart home automation logic example

## Usage

1. **Design State Machine**: Create your state machine diagram in StateSmith (DrawIO or PlantUML)
2. **Configure Transpiler**: Set the transpiler to `Liquid` in your StateSmith configuration
3. **Generate Template**: Run StateSmith to generate the `.liquid` template file
4. **Import to Blockly**: Use the generated template in Blockly Tool's text template blocks
5. **Deploy to Adafruit IO**: Deploy your Blockly workflow to Adafruit IO Actions

## Liquid Template Features

- `{{ variable }}` - Variable interpolation
- `{% if condition %}` - Conditional logic
- `{% for item in collection %}` - Loops
- `{% comment %}` - Comments
- `feeds['feed-name']` - Adafruit IO feed access
- Date filters and mathematical operations
- Whitespace control with `-` tags

## StateSmith Configuration

```toml
transpilerId = "Liquid"
```

Or in code:
```csharp
var settings = new SmRunnerSettings()
{
    transpilerId = TranspilerId.Liquid
};
```

The generated templates can be customized using `RenderConfigLiquidVars` for custom syntax patterns.
